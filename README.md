## The joke

> I accidentally hit reply-all to the whole company, so HR replied-all to the whole company to tell me never to hit reply-all again.

## How it works

Run `node main.ts` (Node 22.18+). The program writes the single-line joke above to `/output/entry.txt` — 130 characters, one line, no trailing newline — ready for the judge.
